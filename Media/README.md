# The World at Your Fingertips

## Media Acquisition
I use SABNZBD as my Usenet downloader, protected by Gluetun for secure VPN connectivity. The Arr stack automates media discovery and downloads: Prowlarr manages indexers, while Lidarr handles music, Sonarr manages TV shows, and Radarr oversees movies, all working together to populate my library based on watchlists and requests.

## Media Viewing
Jellyfin serves as my comprehensive media server, offering a sleek interface to stream movies, TV shows, and music across all my devices. Seerr enhances the experience by facilitating media requests and providing  discovery suggestions to expand my collection.

## Monitoring
Jellystat provides in-depth analytics on Jellyfin usage, tracking viewing habits, user activity, and server performance to help me optimize and maintain my media ecosystem.
